# Pi 应用宿主

这是独立验证中的宿主，当前应用尚未接入。它使用 `upstream-lock.json` 固定源码构建的**完整 Pi coding-agent SDK**。执行循环、会话、压缩、重试、补充输入和工具调度归 Pi；故事权限、草稿、正式采用和执行账本由原生业务网关处理。

构建机需要 Node 24.19.0、Python 3.12 或更高版本：

```powershell
cd agent-host
npm run prepare:upstream
npm run test:smoke
```

准备工具校验源码压缩包、全部原始源码文件与模型目录的 SHA-256，按上游锁文件安装依赖（禁用安装生命周期脚本），运行官方目录补齐和离线构建。源码、依赖和产物保存在忽略的 `.cache` 中。同版本 npm 发行包来自另一提交，不用它替代固定源码。

构建后将完整官方 bundle、Worker、WASM、主题、宿主入口及运行依赖装配到 `.cache/runtime`，记录全部产物路径、大小和 SHA-256。加载前核对构建收据及每个产物，拒绝缺失、额外、篡改或其他版本的文件。安卓以后可将完整目录随包携带，以绝对路径启动其中的 `host/src/entry.mjs`；入口会自动找到同一目录的清单，也可由原生启动环境显式设置 `LISHI_PI_RUNTIME_DIR`。不需要在手机首次启动时安装依赖。

宿主关闭默认文件／Shell 工具、自动资源发现、认证文件、模型目录联网、遥测和缓存预热，只载入显式提供的工具与说明。密钥只在内存使用。玩家技能脚本仍应通过原生受控执行工具，不作为 Node 扩展加载。

模型未配置价格时，Pi 所需的零值仅为计算占位，宿主明确返回 `priceKnown=false`，原生用量界面必须显示金额未知；配置价格后才可计算相应估算。`contextWindowTokens` 表示用户明确配置的模型总窗口，缺少时返回 `modelContextWindowTokens=null` 和 `modelWindowSource=unknown`；填写后来源为 `configured`，不表示已核实服务官方容量。旧字段 `modelWindowVerified` 保留为 `false`，不得据配置存在标成已验证。

`inputTokens` 是 APP 输入预算，默认475000；`maxOutputTokens` 是输出预留及请求输出上限，默认8192。有效输入预算取 APP 预算与“已配置总窗口减输出预留”中的较小值。Pi 的模型运行窗口保留配置总窗口，压缩专用的 `reserveTokens` 设为“运行窗口减有效输入预算”，使压缩阈值遵从 APP 设置，同时保留 SDK 的输出适配。未知模型仅使用“APP输入预算加输出预留加固定SDK的4096安全余量”作为内部运行窗口，不表示服务有该容量。切模型会同步这些值、最近内容保留量和价格状态；输出预留不小于已配置总窗口等无效配置会明确拒绝。

压缩专用的 `reserveTokens` 可能很大，它仅控制何时整理窗口。固定 Pi 版本的摘要生成使用模型的输出上限，不使用这个值作为摘要输出量；分支总结的预算是另一项独立设置。

普通请求与压缩请求的输出上限都不超过当前任务设置；Pi 的服务适配器仍可按实际剩余上下文和自身安全余量进一步缩小输出。这是输出上限，不保证每次都有这么多可用空间。宿主不会通过缩小模型总窗口来消耗 SDK 的4096安全余量，避免将原本可以正常回答的小预算请求误压成1 token。

普通输入发送前，若新输入本身可以容纳，但加上历史超过预算，宿主最多先调用一次 Pi 的 `session.compact()`，为新输入预留空间。切点、完整工具调用组、摘要、检查点与重试仍由 Pi 负责，没有第二套摘要窗口。最终模型请求（包含原始正文、系统说明和工具参数说明）以及压缩请求，都经过同一发送守卫；仍超预算时明确报 `input_budget_exceeded`、不静默截断、不给服务发送该请求。压缩本身超限或失败时保留原有效检查点，新的要求仍交 Pi 留存，不能把失败记为已完成。只保留完整消息可能令一次压缩后仍不足，此时停止并说明。

以上判定使用固定 Pi 的 token 估算与其压缩机制，不是服务官方 tokenizer；尤其中文或其他非拉丁文本可能被低估，不能承诺服务实际 token 数严格等于此值，也不能据 APP 的475000预算承诺模型具备475000容量。可单独运行 `node --test test/budget.test.mjs` 检查超大单条的零发送拒绝、提高预算继续、新输入与历史触发 Pi 压缩、压缩超限保护及模型窗口来源，不需重复全部宿主小样。

`src/entry.mjs` 接受标准输入输出的 JSONL，也支持 `--transport-fd <fd>` 私有套接字。接口包括 `create`、`prompt`、`steer`、`followUp`、`abort`、`compact`、`setModel`、`inspect`、`close`。工具调用发出 `tool_request`，等待 `tool_result`；原生层须先保存请求和结果，并核验权限后回复。工具真实数据和可回读定位会交给模型，业务错误通过 Pi 的错误标志返回，同时保留具体错误内容。

小样只用自有本机模拟服务和临时会话，检查真实 SDK 调用、原文及定位传递、错误、会话恢复、取消和密钥不落盘。它不代表安卓运行、正式 Rust 网关或真实模型质量已经通过。
