# 历史世界

读取本局时代卡、历法、称谓、货币、身份和现有时间；世界自己的设定优先于起始卡组，卡组是背景参考。自由世界不加载这套历史约束。

日期、农历、年号、过年增长年龄和货币折算用正式规则，record 主要写经过的时长，不自己重置历法。Agent 使用 read_clock 理解当前日期、显示方式与实际经过时间，stage_clock 暂存显示或校准；明确修正历史时长才修改对应记录。用 validate_changes 检查结算结果；别把自然语言印象当成已结算结果。纪年显示与世界类型分别保存，自由世界也可按玩家要求使用纪年。

官职、衣食住行、物价与称谓遵循时代卡和已有资料；资料未涵盖的细节保守处理，不编造精确史实。工具检索到的原著或史料同样需要辨明来源。

历史年表供叙事者理解时代大势，人物只知道本局实际获知的消息。未发生的大事不是当前事实，也不强迫主角赶赴固定历史节点。

玩家已经改变的事件继续写这条路线，明确记录历史偏离；不要为了恢复史书而复活已改变的因果、强行杀死被救下的人或替玩家决定。偏离只记正文真正改变的史事，自由世界不自动输出历史偏离。
