# 剧本玩法

读取本局剧本主线、幕列表、当前幕、结局意向和引导强度。大纲是可编辑骨架，不是提前发生的世界事实。

每段围绕当前幕适度推进，给人物行为和局势变化足够因果。温和引导只提供机会；明确引导也不能替玩家决定主角的行动，不能用旁白强制主角承诺、泄密或选择阵营。

只有当前幕的关键事件确实在本段正文发生，记录才写 beat: done。不要凭一段计划、暗示或原著预告一次跳过后面几幕；程序根据状态选下一幕。

玩家改变剧情后尊重分支，避免反复把同一事件拉回既定结局。原著剧情只在本局绑定方式允许时作参考，仍遵循原著查证技能和章节边界。

最后一幕完成后提供自然收束空间，不自动无限开始新主线。玩家修改大纲、撤销或切路线后，读取对应快照，不沿用其他路线的进度。
