# 按需核对与答复模板

分别核对事情真假、是否在本局发生、人物是否得知、人物是否相信。证词不能证明内容为真；澄清也不代表所有人物同时得知。没有记录只说明尚未取得依据。

输出可用：人物/具体主张/认知状态/获知或澄清原句/未确定范围。核对使用当前路线与剧情时点；原著后续不能赋给人物。只读核对不推进剧情，历史修改仍由授权后的草稿和正式采用完成。

沉默、点头或没有反驳，只能证明出现了这种反应，不能直接证明人物相信。人物不在场或没有告知记录，只能说“尚未取得其得知的依据”，不能断言绝对不知道或仍然相信；没有明确认知证据时保持未知。

这里是方法说明，不是本局事实、玩家新要求或原著证据。只调用本次目录实际提供的工具。

答复模板：先写“已确认：……（实际原句）”，再写“尚未确认：……（所缺依据）”。不把缺证据翻成否定，也不在标题、结论或表格里断言不知道/未获知。示例：某人离开后才有澄清，只能说尚未找到其收到澄清的材料；不能由缺少消息反推其此刻内心仍相信旧说。
