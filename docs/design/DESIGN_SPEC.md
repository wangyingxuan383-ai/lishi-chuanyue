# 设计规范

> 界面有两种风格：默认的“宣纸书卷”——纸色底、宋体、朱砂印，夜间用墨色底和烛光色；可选的“墨韵·新中式”——现代应用的大圆角卡片和柔和阴影，配墨黑与一枚朱印。样式在 `src/ui/styles/`：`tokens.css`（两种风格各自的明暗变量）、`base.css`（元素与工具类）、`screens.css`、`play.css`、`overlays.css`、`forms.css`、`settings.css`、`pages.css`、`ink.css`（墨韵的组件差异）、`motion.css`（华丽动画）。

## 1. 气质

像在读一本线装书：纸色底子、宋体正文、朱砂色的印记。界面退到后面，正文是主角。装饰只用几样（纸纹、双线、印章式标签、回合间的小菱形），不用图片、不用花边。

## 2. 风格与明暗（阅读设置里切换）

根元素上 `data-style`（`scroll` 宣纸书卷、`ink` 墨韵）与 `data-theme`（纸张、白天、夜间）相互独立。墨韵的纸张和白天是浅色（暖白底 `#f7f5f0`、卡片白、墨黑 `#1f1d1a`、朱砂 `#b5281c`），夜间是深色（深墨底 `#121212`、卡片 `#1c1c1d`、宣纸色字、朱砂提亮 `#e0503c`），圆角 12～24、多层阴影、顶栏毛玻璃无双线、标题宋体、界面黑体。组件按角色取圆角和阴影：`--radius-lg`、`--radius-pill`、`--elev-1`～`--elev-3`。

宣纸书卷的三套主题：

| 用途 | 纸张（默认） | 白天 | 夜间 |
| --- | --- | --- | --- |
| 底色 `--bg` | #efe5cf 宣纸色，带很淡的纸纹 | #faf7f0 素白，无纸纹 | #131518 墨色，顶部一抹烛光 |
| 卡片、弹层 `--surface` | #f6eedc | #ffffff | #1b1e22 |
| 输入框 `--raised` | #fbf6ea | #ffffff | #1f2226 |
| 正文 `--fg` | #2a2019 墨色 | #26201a | #e9dcc5 暖米色 |
| 次要文字 `--muted` | #6f5d47 | #6b5f50 | #9a9183 |
| 分隔线 `--line` | #d9c8a7 | #e6dccb | #2b2f35 |
| 强调 `--accent` | #a83221 朱砂 | #a83221 | #d4a04c 烛金 |
| 强调上的字 `--on-accent` | #ffffff | #ffffff | #1c1508 |
| 好 / 坏 / 提醒 | #3e6b47 / #a83221 / #7d560c | 同左 | #9fcf95 / #e7896b / #e6b450 |

对比度（按 WCAG 计算）：纸张主题正文约 13:1、次要文字约 5:1、朱砂底白字约 6.7:1；夜间主题次要文字约 5.9:1。14 像素以上的字都在 4.5:1 以上。

## 3. 字体与字号

- 正文：宋体。应用自带思源宋体（Noto Serif SC 可变字重，SIL OFL，`@fontsource-variable/noto-serif-sc`，按字符分片只加载用到的字，约 6MB），不再依赖手机有没有宋体。阅读设置可以改成黑体。
- 标题、选项、标签、主按钮：也用宋体，保持书卷气。
- 其余界面（说明文字、输入框、设置项）：系统黑体。
- 字号：正文默认 18（阅读设置可调），行高 2.0，段首空两格；顶栏标题 17；卡片标题 17；弹层标题 17；正文以外的说明 14；标签 12。
- 楷体（如霞鹜文楷）暂不附带。

## 4. 间距、圆角、触控

- 以 4 为单位，只用这六档：`--s1` 4、`--s2` 8、`--s3` 12、`--s4` 16、`--s5` 24、`--s6` 32。页面左右留白 16，正文 18。旧样式里的 2、6、10、14 等零散值在整理时就近归档。
- 圆角克制：`--radius` 4（按钮、输入框），`--radius-card` 3（卡片、标签），`--radius-sheet` 10（弹层顶部），`--radius-dialog` 6（对话框）。
- 可点的东西至少 44 像素高（`--tap`），标签页和回合下的小按钮也一样。
- 层级只用这几层：`--z-bar` 5（顶栏）、`--z-backdrop` 20、`--z-sheet` 21、`--z-dialog` 31、`--z-toast` 40。

### 布局工具类

不写内联 `style`，改用这些类（实现见 `base.css`）：

| 类 | 作用 |
| --- | --- |
| `.row` / `.stack` / `.grow` | 横排（间距 10）、竖排（间距 12）、占满剩余 |
| `.gap-0`、`.gap-1`～`.gap-4`、`.gap-10` | 把间距改成 0、4/8/12/16、10（竖排里要和横排一样的间距时用） |
| `.m-0`、`.mt-0`、`.mb-0`、`.mt-1`～`.mt-4` | 去掉外边距、去掉上或下外边距、上外边距 4/8/12/16 |
| `.between`、`.wrap`、`.start`、`.center` | 两端对齐、换行、自身顶端对齐、子项居中对齐 |
| `.small`、`.warn-text` | 小一号文字（13px）、警示色文字 |
| `.t-left` / `.t-center` / `.t-right` | 文字对齐 |

只有运行时算出来的值（缩进深度、进度宽度）才允许内联。颜色一律用主题变量，组件里不写十六进制颜色（状态栏颜色、分享卡导出图片除外，二者需要实际颜色值）。

## 4.1 给玩家看的词

界面文字用玩家的话。下面这些词在开发者模式以外不出现：

| 不说 | 改说 |
| --- | --- |
| Agent、Agent 助手 | 助手 |
| token、tokens | 字（显示“约 x 万字”） |
| 上下文、上下文用量 | 记忆、记忆占用 |
| MCP | 外部工具服务 |
| JSON、TXT、MD 等格式名 | 只在选文件处说明，其他地方不提 |
| 会话、执行、租约、指纹、快照 | 对话、任务；后三个不出现 |

## 5. 组件

| 组件 | 样子 |
| --- | --- |
| 顶栏 | 半透明纸色，下边是双线 |
| 主按钮 | 朱砂底白字（夜间金底墨字），宋体，字距稍宽 |
| 次按钮 | 纸色底、细边框 |
| 卡片（世界、模板） | 浅纸色；首页书架上每个故事是一册线装书（订线书脊、竖排题签、朱砂朝代印，八种书衣颜色），只有“继续”那张卡保留左边的朱砂竖线 |
| 回合 | 你的行动前有一道朱砂短竖线；回合之间一个小菱形（夜间是 ✦）；段首空两格 |
| 变化标签 | 像小印章：细边框、透明底、宋体；好的绿、坏的朱砂 |

| 态度标签 | 朱砂细框小字 |
| 提示条 | 浅朱砂底，左边一道朱砂线 |

| 人物名章 | 人物列表里用名字首字做朱文小印，代替头像 |
| 玩法横幅 | 剧本、挑战时在顶栏下一条 40 像素的细横幅，点开是剧本页或挑战页 |

| 输入栏 | 一条：方式按钮、自动增高的输入框（润色、展开两个图标随键盘出现）、主按钮（继续／发送／停止，图标加字）；幕后要求是栏上方一枚可删的小签 |

| 首页 | 大“继续”卡（书衣、书名、此时此地、最后一句、正在写的状态），新故事入口，两列书架；加载时骨架屏 |
| 设置首页 | 顶部 AI 服务卡，分组条目带图标和当前值；阅读与外观页顶部是两种风格的实时预览卡 |

## 6. 动效

阅读设置的“动画”有三档：**华丽**（默认）、**简洁**、**关**。系统设置了“减少动态效果”时一律按关。简洁只留下面“基础”一栏；华丽的效果都写在 `motion.css`，只在 `:root[data-motion="rich"]` 下生效。只动 `transform`、`opacity`、`filter`，单个不超过约 700 毫秒，不挡操作。时长和缓动用变量：`--dur-fast` 150、`--dur` 200、`--dur-slow` 260，`--ease-out` 出现、`--ease-in` 离开，`--spring-soft` 带一次轻回弹。

基础（简洁和华丽都有）：
- 弹层升起、关闭时下沉淡出；对话框淡入淡出；吐司淡出；角色面板滑入滑出；菜单里点了某项直接关闭。
- 新的回合、选项、变化行、展开的折叠内容淡入上移；按钮按下下沉 1 像素，菜单项和卡片按下显出浅底。
- 生成时读者停在上面，回到底部的箭头上有呼吸的小点；首字前一支毛笔在纸上画圈，配已等秒数。
- 弹层可以按住把手或标题往下拉，跟手；拉够了或甩一下就落下关闭，否则弹回。

华丽另加：
- 页面切换用 View Transitions：进入新页面是墨迹从下方晕开，返回时旧页面向右滑走；从首页打开一本书，书衣长成故事页。
- 列表依次弹入（首页书架、设置条目、菜单项、选项），弹层和对话框带回弹。
- 你的行动从输入栏飞进故事；正文一句句从模糊的墨迹变清楚；写完时这一段扫过一道淡金光；变化里的数字滚动到位，加闪绿、减闪红。
- 目标达成、新篇、结识新人物、一幕演完时，一枚朱砂印旋转着盖下，四周飞溅墨点，配一次轻震。
- 按钮按下有墨晕涟漪，发送按钮发出一圈朱砂光环；游玩页背景有缓慢流动的光晕（宣纸是烛光，墨韵是墨烟）。
- 触感（震动）：长按、发送、写完一段、出错、盖印时轻振一下，跟随阅读设置里的“触感”。

## 7. 图标与启动页

- 应用名：穿越小说模拟（“历史穿越”保留为一种玩法的名字）。
- 图标：墨色底上一枚朱砂圆印，竖排宣纸色“穿越”，外绕一道开口的淡金笔触环，环口一点金光，暗含穿越时空。安卓自适应图标背景色为墨色 `#15130F`，单色图层暂用通知的印章轮廓。印章文字用思源宋体（SIL OFL）渲染成图片，源文件在 `assets/`：`app-icon.svg` 给安卓用（印章留白，落在启动器遮罩保留的圆里），`app-icon-desktop.svg` 给电脑用（印章撑满）。重新生成的步骤见[开发说明](../DEVELOPMENT.md#图标)。
- 启动页：打开时先显示同一枚印章和应用名，纸色底（夜间墨色底）；安卓原生启动背景也设为纸色，避免白屏一闪。
