# 设计规范

> 界面的样子叫“宣纸书卷”：纸色底、宋体、朱砂色的印记；夜间主题用墨色底和烛光般的暖色字。实现都在 `src/ui/styles/base.css`。

## 1. 气质

像在读一本线装书：纸色底子、宋体正文、朱砂色的印记。界面退到后面，正文是主角。装饰只用几样（纸纹、双线、印章式标签、回合间的小菱形），不用图片、不用花边。

## 2. 三套主题（阅读设置里切换）

| 用途 | 纸张（默认） | 白天 | 夜间 |
| --- | --- | --- | --- |
| 底色 `--bg` | #efe5cf 宣纸色，带很淡的纸纹 | #faf7f0 素白，无纸纹 | #131518 墨色，顶部一抹烛光 |
| 卡片、弹层 `--surface` | #f6eedc | #ffffff | #1b1e22 |
| 输入框 `--raised` | #fbf6ea | #ffffff | #1f2226 |
| 正文 `--fg` | #2a2019 墨色 | #26201a | #e9dcc5 暖米色 |
| 次要文字 `--muted` | #6f5d47 | #6b5f50 | #9a9183 |
| 分隔线 `--line` | #d9c8a7 | #e6dccb | #2b2f35 |
| 强调 `--accent` | #a83221 朱砂 | #a83221 | #d4a04c 烛金 |
| 强调上的字 `--on-accent` | #ffffff | #ffffff | #1c1508 |
| 好 / 坏 / 提醒 | #3e6b47 / #a83221 / #7d560c | 同左 | #9fcf95 / #e7896b / #e6b450 |

对比度（按 WCAG 计算）：纸张主题正文约 13:1、次要文字约 5:1、朱砂底白字约 6.7:1；夜间主题次要文字约 5.9:1。14 像素以上的字都在 4.5:1 以上。

## 3. 字体与字号

- 正文：宋体（`--serif`：思源宋体、宋体等，手机上用系统自带的；没有就退回黑体）。阅读设置可以改成黑体。
- 标题、选项、标签、主按钮：也用宋体，保持书卷气。
- 其余界面（说明文字、输入框、设置项）：系统黑体。
- 字号：正文默认 18（阅读设置可调），行高 2.0，段首空两格；顶栏标题 17；卡片标题 17；弹层标题 17；正文以外的说明 14；标签 12。
- 楷体（如霞鹜文楷）要随安装包附带字体，安装包会大十几 MB，暂时不做。

## 4. 间距、圆角、触控

- 以 4 为单位，只用这六档：`--s1` 4、`--s2` 8、`--s3` 12、`--s4` 16、`--s5` 24、`--s6` 32。页面左右留白 16，正文 18。旧样式里的 2、6、10、14 等零散值在整理时就近归档。
- 圆角克制：`--radius` 4（按钮、输入框），`--radius-card` 3（卡片、标签），`--radius-sheet` 10（弹层顶部），`--radius-dialog` 6（对话框）。
- 可点的东西至少 44 像素高（`--tap`），标签页和回合下的小按钮也一样。
- 层级只用这几层：`--z-bar` 5（顶栏）、`--z-backdrop` 20、`--z-sheet` 21、`--z-dialog` 31、`--z-toast` 40。

### 布局工具类

不写内联 `style`，改用这些类（实现见 `base.css`）：

| 类 | 作用 |
| --- | --- |
| `.row` / `.stack` / `.grow` | 横排（间距 10）、竖排（间距 12）、占满剩余 |
| `.gap-0`、`.gap-1`～`.gap-4`、`.gap-10` | 把间距改成 0、4/8/12/16、10（竖排里要和横排一样的间距时用） |
| `.m-0`、`.mt-0`、`.mb-0`、`.mt-1`～`.mt-4` | 去掉外边距、去掉上或下外边距、上外边距 4/8/12/16 |
| `.between`、`.wrap`、`.start`、`.center` | 两端对齐、换行、自身顶端对齐、子项居中对齐 |
| `.small`、`.warn-text` | 小一号文字（13px）、警示色文字 |
| `.t-left` / `.t-center` / `.t-right` | 文字对齐 |

只有运行时算出来的值（缩进深度、进度宽度）才允许内联。颜色一律用主题变量，组件里不写十六进制颜色（状态栏颜色、分享卡导出图片除外，二者需要实际颜色值）。

## 4.1 给玩家看的词

界面文字用玩家的话。下面这些词在开发者模式以外不出现：

| 不说 | 改说 |
| --- | --- |
| Agent、Agent 助手 | 助手 |
| token、tokens | 字（显示“约 x 万字”） |
| 上下文、上下文用量 | 记忆、记忆占用 |
| MCP | 外部工具服务 |
| JSON、TXT、MD 等格式名 | 只在选文件处说明，其他地方不提 |
| 会话、执行、租约、指纹、快照 | 对话、任务；后三个不出现 |

## 5. 组件

| 组件 | 样子 |
| --- | --- |
| 顶栏 | 半透明纸色，下边是双线 |
| 主按钮 | 朱砂底白字（夜间金底墨字），宋体，字距稍宽 |
| 次按钮 | 纸色底、细边框 |
| 卡片（世界、模板） | 浅纸色；首页书架上每个故事是一册线装书（订线书脊、竖排题签、朱砂朝代印，八种书衣颜色），只有“继续”那张卡保留左边的朱砂竖线 |
| 回合 | 你的行动前有一道朱砂短竖线；回合之间一个小菱形（夜间是 ✦）；段首空两格 |
| 变化标签 | 像小印章：细边框、透明底、宋体；好的绿、坏的朱砂 |
| 建议选项 | “一、二、三”编号，虚线分隔，不用按钮框 |
| 标签页 | 宋体，选中的下面一道朱砂线 |
| 态度标签 | 朱砂细框小字 |
| 提示条 | 浅朱砂底，左边一道朱砂线 |
| 弹层 | 纸色，顶边双线，从下面升起；一律挂在页面最上层（`body`），不受所在容器的动画和裁切影响 |
| 人物名章 | 人物列表里用名字首字做朱文小印，代替头像 |

## 6. 动效

原则：短（150～260 毫秒）、轻（只动透明度和几个像素的位移）、不挡操作。时长和缓动用 `base.css` 里的变量：`--dur-fast` 150、`--dur` 200、`--dur-slow` 260，`--ease-out` 用于出现，`--ease-in` 用于离开。

- 弹层从下升起 200 毫秒，背景渐暗；关闭时（返回键、点背景、×）先下沉淡出约 150 毫秒再移除。菜单里点了某一项就直接关闭，不等动画。
- 对话框淡入并从 0.97 放大到原大，关闭时淡出；吐司到时间先淡出再消失；角色面板从右滑入，关闭时向右滑出。
- 进入新页面从右侧 14 像素淡入滑进，返回时露出的页面只淡入；动画结束后不留下位移，不影响固定定位和阅读位置。
- 新的回合、选项、变化标签、展开的折叠内容淡入并上移几个像素；折叠项的 › 展开时转 90 度。
- 按钮按下时下沉 1 像素；菜单项、选项卡片、书架卡片、折叠标题按下时显出浅朱砂底，图标按钮显出浅墨底。
- 生成时读者停在上面，回到底部的箭头上有一个呼吸的小点，表示下面有新字。
- 触感（震动）：长按、发送、写完一段、出错时轻振一下，跟随阅读设置里的“触感”。
- 系统设置了“减少动态效果”，或阅读设置里把“动画”关掉时，全部关掉，弹层立即关闭。

## 7. 图标与启动页

- 应用名：穿越小说模拟（“历史穿越”保留为一种玩法的名字）。
- 图标：宣纸色圆角方底上一枚朱砂印章，竖排白字“穿越”。印章文字用思源宋体（SIL OFL）渲染成图片，源文件在 `assets/`：`app-icon.svg` 给安卓用（印章留白，落在启动器遮罩保留的圆里），`app-icon-desktop.svg` 给电脑用（印章撑满）。重新生成的步骤见[开发说明](../DEVELOPMENT.md#图标)。
- 启动页：打开时先显示同一枚印章和应用名，纸色底（夜间墨色底）；安卓原生启动背景也设为纸色，避免白屏一闪。
