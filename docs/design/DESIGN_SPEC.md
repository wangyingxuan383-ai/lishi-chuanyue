# 设计规范

> 界面有两种风格：默认的“宣纸书卷”——纸色底、宋体、朱砂印，夜间用墨色底和烛光色；可选的“墨韵·新中式”——现代应用的大圆角卡片和柔和阴影，配墨黑与一枚朱印。样式在 `src/ui/styles/`：`tokens.css`（两种风格各自的明暗变量）、`base.css`（元素与工具类）、`screens.css`、`play.css`、`overlays.css`、`forms.css`、`settings.css`、`pages.css`、`ink.css`（墨韵的组件差异）、`motion.css`（华丽动画）。

## 1. 气质

像在读一本线装书：纸色底子、宋体正文、朱砂色的印记。界面退到后面，正文是主角。装饰克制而有出处（纸纹、乌丝双线、手刻石章、鱼尾题签、章回云纹、水墨淡彩空状态小景），不用位图花边、不用刺眼纯色。

## 2. 风格与明暗（阅读设置里切换）

根元素上 `data-style`（`scroll` 宣纸书卷、`ink` 墨韵）与 `data-theme`（纸张、白天、夜间）相互独立。墨韵的纸张和白天是浅色（暖白底 `#f7f5f0`、卡片白、墨黑 `#1f1d1a`、朱砂 `#b5281c`），夜间是深色（深墨底 `#121212`、卡片 `#1c1c1d`、宣纸色字 `#ede6da`、实底朱砂 `#be2f21`、前景朱砂字 `--accent-text: #ee7a64`），圆角 12～24、多层阴影、顶栏毛玻璃无双线、标题宋体、界面黑体。组件按角色取圆角和阴影：`--radius-lg`、`--radius-pill`、`--elev-1`～`--elev-3`。

墨韵另有一层装饰：底色上是水墨晕染和宣纸纤维，页脚一抹淡淡的远山（固定在屏幕上，不随内容滚动）；较大的卡片（首页卡、设置分组、这一版新增、新故事、接下来）带描金细边（`--gilt-soft`）和两个对角的回纹角（`--meander`、`--meander-br`）；小标题下是一道金色笔触；夜间的大标题（首页、场景标题、书架便签）是描金渐变字；主按钮多一圈淡金内边。

宣纸书卷的三套主题：

| 用途 | 纸张（默认） | 白天 | 夜间 |
| --- | --- | --- | --- |

## 3. 字体、排版与翻页

- 正文：宋体。应用自带思源宋体（Noto Serif SC 可变字重，SIL OFL，`@fontsource-variable/noto-serif-sc`，按字符分片只加载用到的字，约 6MB），不再依赖手机有没有宋体。阅读设置可以改成黑体。
- 标题、选项、标签、主按钮：也用宋体，保持书卷气。
- 其余界面（说明文字、输入框、设置项）：系统黑体。
- 字号：正文默认 18（阅读设置可调），行高 2.0，段首空两格；顶栏标题 17；卡片标题 17；弹层标题 17；正文以外的说明 14；标签 12。
- 阅读方式支持**上下滚动**与**左右翻页**随时切换：翻页模式按当前视口高度与整数页宽做 CSS 多栏自动分页，长回合自然跨页、绝不裁字，底部留一行极淡的章节与页码提示。

## 4. 间距、圆角、触控与多尺寸适配

- 以 4 为单位，只用这六档：`--s1` 4、`--s2` 8、`--s3` 12、`--s4` 16、`--s5` 24、`--s6` 32。页面左右留白 16，正文 18。
- 圆角克制：`--radius` 4（按钮、输入框），`--radius-card` 3（卡片、标签），`--radius-sheet` 10（弹层顶部），`--radius-dialog` 6（对话框）。
- 可点的东西至少 44 像素高（`--tap`），标签页和回合下的小按钮也一样。
- 响应式断点覆盖 `320px` 小屏与大显示缩放、`360px～430px` 常规竖屏手机、`640px～999px` 折叠屏展开内屏与小平板（角色面板自动收为右侧抽屉、弹层与输入栏居中收束）、`960px+` 桌面宽屏（双首页左景右案、游玩页左文右档双栏）。
- 层级只用这几层：`--z-bar` 5（顶栏）、`--z-backdrop` 20、`--z-sheet` 21、`--z-dialog` 31、`--z-toast` 40。

### 布局工具类

不写内联 `style`，改用这些类（实现见 `base.css`）：

| 类 | 作用 |
| --- | --- |
| `.row` / `.stack` / `.grow` | 横排（间距 10）、竖排（间距 12）、占满剩余 |
| `.gap-0`、`.gap-1`～`.gap-4`、`.gap-10` | 把间距改成 0、4/8/12/16、10（竖排里要和横排一样的间距时用） |
| `.m-0`、`.mt-0`、`.mb-0`、`.mt-1`～`.mt-4` | 去掉外边距、去掉上或下外边距、上外边距 4/8/12/16 |
| `.between`、`.wrap`、`.start`、`.center` | 两端对齐、换行、自身顶端对齐、子项居中对齐 |
| `.small`、`.warn-text` | 小一号文字（13px）、警示色文字 |
| `.t-left` / `.t-center` / `.t-right` | 文字对齐 |

只有运行时算出来的值（缩进深度、进度宽度、书页位移）才允许内联。颜色一律用主题变量，组件里不写十六进制颜色（状态栏颜色、分享卡与电子书封面矢量图除外，需要独立物理色值）。

## 6. 动效

阅读设置的“动画”有三档：**华丽**（默认）、**简洁**、**关**。系统设置了“减少动态效果”时一律按关，且强制清零一切动画与延迟（`animation-delay: 0ms`）。简洁只留基础淡入与位移；华丽的效果集中在 `motion.css`，全程只驱动 GPU 合成层属性（`transform`、`opacity`、`filter`），零布局抖动、零背景重绘。

基础（简洁和华丽都有）：
- 弹层升起、关闭时下沉淡出；对话框淡入淡出；吐司淡出；角色面板滑入滑出；翻页模式下书页跟手平移吸附。
- 新的回合、选项、变化行、展开的折叠内容淡入上移；按钮按下下沉 1 像素，菜单项和卡片按下显出浅底。
- 生成时读者停在原页或原位置，回到底部/末页的按钮带呼吸小点；首字前一支毛笔在纸上画圈，配已等秒数。

华丽另加：
- 页面切换用 View Transitions 墨迹晕染过渡；从首页翻开书本时先播 360 毫秒的浮书/抽书掀封与金粉迸散，随后以轻快淡入衔接正文，总时长约 600 毫秒。
- 场景首页远山分层视差慢移、飘云、金粉升起；书架首页书册依次落架。
- 你的行动从输入栏飞进故事；正文流式落笔渐显；写完时扫过一道合成层淡金光泽；达成里程碑时一枚手刻朱砂印旋转盖下并飞溅墨点，不影响小传印谱常驻展示。

## 7. 图标与启动页

- 应用名：穿越小说模拟（“历史穿越”保留为一种玩法的名字）。
- 图标：墨色底上一枚朱砂圆印，竖排宣纸色“穿越”，外绕一道开口的淡金笔触环，环口一点金光，暗含穿越时空。安卓自适应图标背景色为墨色 `#15130F`。源文件在 `assets/`：`app-icon.svg` 给安卓用，`app-icon-desktop.svg` 给电脑用。重新生成的步骤见[开发说明](../DEVELOPMENT.md#图标)。
- 启动页：打开时先显示同一枚印章和应用名，纸色底（夜间墨色底）；安卓原生启动背景与状态栏初始色同为宣纸色 `#efe5cf`，避免冷启动白屏或黑条闪烁。
