本文件是 v3 任务完成情况的**唯一**来源。计划内容见 [PLAN_V3](PLAN_V3.md)，决策原因见 [DECISIONS](DECISIONS.md)，当前现场见 [STATE](STATE.md)。v2 的 M00～M07 旧台账已归档到 [archive/v2/TASKS.md](archive/v2/TASKS.md)，不再更新。

## 使用规则

- 状态只用：待开始、进行中、受阻、待验收、已完成、已取消。正常流转：待开始 → 进行中 → 待验收 → 已完成。
- 认领任务时把状态改为“进行中”，写明负责人和修改范围；同一时间同一模块只有一个负责人。
- 标记“已完成”必须同时填写：实际成果位置、验证方法与结果、完成时间。“代码写完”“测试通过”“真机通过”“用户试玩通过”分别记录，不能互相代替。
- 阶段验收任务（每阶段最后一个）必须包含用户试玩问卷结果（D109），R00、R01 除外；R02、R03 的“记得住”只记录不计入门槛。按 D118，开发不在阶段之间停下等试玩：验收任务在可玩版本装到手机后改为“待验收”，问卷集中填写。
- 新问题或新想法：属于现有任务范围的写进该任务的“阻塞/遗留”；否则在“候选池”登记，经用户同意后才转为正式任务，避免范围膨胀。
- 时间使用 Asia/Shanghai，日期写 `YYYY-MM-DD`。
