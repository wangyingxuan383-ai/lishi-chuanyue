# 时代包写作指南

> 版本 1，2026-10-17（Asia/Shanghai）。对应 [PLAN_V3](../PLAN_V3.md) 第 3.3、5.3 节，决策 D111、D119、D120，任务 R03-T001。类型定义在 `src/content/eras/types.ts`，校验在 `src/engine/era/validate.ts`。

## 1. 时代包是什么

时代包是某个时代、某个地方的一份资料：纪年、货币与物价、称谓、日常细节、身份、历史大事、时代错误清单。它是**可选的增强**（D117）：开局时选了时代包，叙事者就能写对钱、称谓和器物，程序就能按年号换算日期；不选也能玩任何时代，只是这些细节交给模型自己发挥。

每个时代包是 `src/content/eras/` 下的一个 TypeScript 模块（如 `tang-748.ts`），导出一个 `EraPack` 对象，并在 `src/content/eras/index.ts` 的 `ERAS` 里登记。内容只能是普通数据（字符串、数字、数组、对象），不写函数，以后可以原样导出成 JSON。

## 2. 校验

- `corepack pnpm vitest run src/engine/era`：所有已登记的时代包必须零问题通过，测试同时检查 id 不重复、每个身份都出现在开局模板里。
- `node_modules/.bin/tsx scripts/check-eras.ts`：逐包列出问题和每个月的摘录长度，写包时随手跑。

校验会发现：缺字段或空文字；年号表顺序错乱、两个年号同月开始、年号重名；货币单位缺换算、不是从大到小、大单位不是小单位的整数倍、最小单位不是 1、别名指向不存在的单位；开局日期与年号表不符、日子超出当月天数；身份、禁忌、事件等少于最低条数；身份阶层少于 4 个，或缺少男性、女性、不限性别中的任何一种；不限性别的身份里出现决定性别的词；时间线没按先后排列；来源网址或查阅日期格式不对；摘录删到最少仍超过 1000 字。

## 3. 字段说明

“去向”说明这个字段会影响哪里：**提示词**（叙事者看到的【时代资料】）、**界面**、**记账**、**历法**、**评测**。

| 字段 | 写什么 | 去向 |
|---|---|---|
| `id` | 小写字母、数字、连字符，如 `tang-748`。存进世界记录，**发布后不能改** | 界面、存档 |
| `title` | “唐 · 天宝七载 · 长安” | 界面（时代资料选择、此时此地）、提示词标题 |
| `dynasty` | “唐”；与开局年份一起组成模板卡片上的“唐 · 天宝七载” | 界面 |
| `blurb` | 一两句话介绍这个时代的氛围 | 界面（以后的时代介绍） |
| `calendar.lunar` | 中国背景写 `true`（简化农历：单月 30 天、双月 29 天，不设闰月）；西方背景写 `false`（公历月长，年号写“公元”“公元前”） | 历法 |
| `calendar.eras` | 年号表，按时间先后排。每项：`name`、`startCe`（改元那一年的公元年，公元前写负数）、`startMonth`（改元月份，默认正月）、`firstYear`（改元时不从元年数起才写）、`yearWord`（天宝、至德写“载”） | 历法：时间走到改元那个月的月初自动换年号；表外的年号一直往下数 |
| `start` | 开局默认日期（`GameDate`，`ceYear` 必须与年号表推算一致）、时刻（0～23）和地点 | 开场提示词（“开局日期是……，除非故事设定另有说明”）；开场没给出可用日期时用它 |
| `premise` | 不用模板、只选时代包时的默认故事设定 | 开局表单 |
| `situation` | 开局时谁当权、人们在谈什么，写给叙事者看，一百多字 | 提示词“时局” |
| `currency` | 货币单位，从大到小，`value` 以最小单位计（如贯 1000、文 1）；`aliases` 是解析时接受的别称（缗→贯、钱→文） | 记账：钱一律以最小单位的整数保存，显示时换成“1 贯 200 文”；模型写的“三贯”“一贯半”按这里换算 |
| `currencyNote` | 一两句话说明钱怎么用（铜钱、绢帛、银两的地位） | 提示词“货币” |
| `startMoney` | 开场没给钱数时的初始钱，以最小单位计 | 记账 |
| `prices` | 物价锚点。`item` 与 `price` 直接连起来读（“米一斗”+“约十几文”）。`basis` 写“史料”（来源里有出处）或“估算”（与史料相符的推算） | 提示词“物价” |
| `address` | 称谓：`term` 是称呼，`usage` 是对谁用、怎么用，尽量短 | 提示词“称谓” |
| `identities` | 身份签，**每个都是一张开局模板**（见第 4 节） | 开局表单的灵感卡片、“随便穿” |
| `places` | 主要地点，描述十字左右 | 提示词“地点” |
| `timeline` | 历史大事：`ceYear`、`month`（该时代历法的月份）、`title`、`kind`（“固定”是天灾、远方战事等玩家改变不了的；“可变”是人的抉择，玩家可能改变） | 提示词“近来大事”（过去一年内的事件）；R05 起进入月报和“历史偏离” |
| `daily` | 日常细节，一条一件事；只在某几个月才有的写 `months`（冬至写 `[11]`） | 提示词“风物”：当月的节令细节优先 |
| `taboos` | 时代错误清单（见第 5 节） | 提示词“不要出现”；评测统计时代错误；R07 的时代错误提示 |
| `style` | 叙述和对白应该是什么味道 | 提示词“文风” |
| `names` | 常见姓氏和男女名字 | 模板和“随便穿”随机取名（身份可用 `surnames` 覆盖，如皇子都姓李） |
| `sources` | 来源：`title`、`url`（可选）、`accessed`（查阅日期 YYYY-MM-DD）、`covers`（这条来源支持哪些内容） | 抽查与以后的“查一查” |
| `confidence` | 可信度“高 / 中 / 低”和说明：哪些有史料，哪些是估算，已知的简化 | 抽查记录 |

## 4. 身份签（开局模板）

- 每个时代包至少 8 个身份，覆盖至少 4 个阶层，男性、女性、不限性别各至少一个。不要都写成底层人物，也不要都写成贵人。
- `gender` 只在身份本身隐含性别时才写（皇子、宫女、女冠、举子）；写 `null` 时，`title`、`text`、`hint` 和 `premise` 里都**不能出现决定主角性别的词**（他 / 她、郎君、娘子、儿子、女儿等），界面会让玩家自己选性别。
- `text` 用“你”来写：你是谁、处在什么麻烦里。`hint` 是开场第一幕。`premise` 省略时用时代包的 `premise`。
- 模板卡片上的朝代标签由 `dynasty` 和开局年份自动生成；`id` 在所有时代包和手写模板之间都不能重复。

## 5. 时代错误清单

- 每个时代包至少 20 条。`name` 是不该出现的东西或说法（叙事者会看到）；`note` 说明为什么（给玩家和以后的检查看）；`instead` 是该用什么代替，写得越短越好（叙事者会看到）。
- `match` 是评测统计时在正文里查找的字面词，默认就是 `name`。`name` 里有顿号或说明文字时要写 `match`；容易误报的（如“大人”在唐代可以称父母）写 `[]`，只提醒叙事者、不做字面统计。
- 只写这个时代真正容易写错的东西：后世的器物、作物、称呼、官名、机构、制度。

## 6. 提示词摘录怎么生成

`src/engine/era/excerpt.ts` 按当前游戏日期生成【时代资料】，顺序是：时局、货币、物价、称谓、风物（当月节令在前）、近来大事、地点、文风、不要出现。

摘录上限 1000 字（中文按一字一 token 保守估计，对应计划中“时代包摘录 ≤1k”）。超过时依次删减：地点 → 风物 → 近来大事 → 物价 → 称谓，每类至少保留几条（地点 3、风物 3、大事 1、物价 4、称谓 5）；时局、货币、文风和全部禁忌不删。删到最少仍超长时校验会报错，这时要精简文字，而不是减少禁忌。

## 7. 新增一个时代包

1. 按第 3 节写好 `src/content/eras/<id>.ts`，在 `index.ts` 的 `ERAS` 里登记。
2. 跑 `scripts/check-eras.ts` 和 `vitest run src/engine/era`，直到零问题。
3. 把原来指向这个时代的手写模板删掉或并入身份签（`src/content/templates.ts`）。
4. 抽查史实，记到 [时代包抽查记录](../validation/R03_ERAS.md)：抽了哪些条目、依据什么来源、发现的问题和处理。
