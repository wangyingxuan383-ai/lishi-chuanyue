# R03 时代包抽查记录

> 2026-10-17（Asia/Shanghai）。任务状态以 [TASKS](../TASKS.md) 为准；时代包格式见 [时代包写作指南](../contracts/ERA_PACK.md)。

## 方法

1. 时代包由 AI 起草，按 D111 标注来源和可信度。
2. 每个包抽查年号表、开局日期、时间线、物价、称谓、日常细节和时代错误清单，逐条对照正史、政书、笔记或可靠的百科条目，记录结论和网址。
3. 发现的错误直接改进时代包，在这里记下改了什么；拿不准的写得模糊些，或在 `confidence.note` 里说明。

已据此改正时代包：米价改为“不到二十文”，新增“面一斗约三十二文”，绢价改为“约二百一十文”，短工改为“约数十文”；“万年县不良帅”改为“万年县不良人”；崇仁坊改为“候选官员多在此投宿”；天宝元年起州改郡、刺史改称太守，称谓与禁忌里的“刺史”改为“太守”；来源补上网址与查阅日期，可信度说明写明怛罗斯月份两说。

起草时已改正：旧版提示词把 748 年的杨钊称作“杨国忠”；皇子封号由“郡王”改为“亲王”；“西市客栈”改为“邸店”。

2026-10-17 补正（来自 R05 评测 G2 的审读）：“女子出行戴帷帽”不合天宝年间——《旧唐书·舆服志》记开元初宫人骑马“皆著胡帽，靓妆露面”，“帷帽之制，绝不行用”（[维基文库 · 旧唐书卷45](https://zh.wikisource.org/zh-hans/%E8%88%8A%E5%94%90%E6%9B%B8/%E5%8D%B745)）。日常一条改为“女子多戴胡帽露面骑马，也有着男装的”。文风一条加上“别写成明清公案腔”，针对 150 回合评测里大量出现的捕头、三班衙役、差爷官爷、小的、咱们。

已知简化：天宝元年、二年实称“年”，本包一律写“载”；上元二年九月至宝应改元之间废年号、以建子月为岁首的特殊纪年没有处理。
