# R03 时代包抽查记录

> 2026-10-17（Asia/Shanghai）。任务状态以 [TASKS](../TASKS.md) 为准；时代包格式见 [时代包写作指南](../contracts/ERA_PACK.md)。

## 方法

1. 时代包由 AI 起草，按 D111 标注来源和可信度。
2. 每个包抽查年号表、开局日期、时间线、物价、称谓、日常细节和时代错误清单，逐条对照正史、政书、笔记或可靠的百科条目，记录结论和网址。
3. 发现的错误直接改进时代包，在这里记下改了什么；拿不准的写得模糊些，或在 `confidence.note` 里说明。
