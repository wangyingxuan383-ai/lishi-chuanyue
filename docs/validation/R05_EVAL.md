## G1：过些日子（2026-10-17，13 次调用）

落第举子开局，走一回合后，从同一回合“过一个月；照常过日子”“过一年；读书”各写 5 个版本，10 个版本全部成功。

| 项目 | 结果 |
| --- | --- |
| 记录的时长与程序换算 | 10/10 一致（“一个月”30 天，“一年”365 天） |
| 跨过年关长一岁 | 一年的 5 个版本都从 22 岁到 23 岁，有“过年了，23 岁”标签 |
| 年表大事 | 一年的 5 个版本都跨过天宝八载六月，都有“📜 哥舒翰攻克石堡城”标签 |
| 钱的变化 | 一个月 +42～+720 文，一年 +120～+910 文；落第举子替人抄书的收入，合情理 |
| 见闻卡片 | 9/10 有天下、市面、人情三项；1 个一年的版本没写 |
| 遇事提前停下 | 0/10：没有一个版本提前停下 |
| 其他 | 一个版本把“开元通宝×180”记成了物品（钱也加了 180），钱被记了两遍 |

**结论**：时长、年龄、年表大事、见闻都可靠；“遇到要主角拿主意的事就停”没有出现，已在 turn-12 里加强；钱被记成物品的问题已在记账里拦下。turn-12 之后复测“提前停下”。
