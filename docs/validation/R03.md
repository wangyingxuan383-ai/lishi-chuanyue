## 手机试玩清单（R02 与 R03 一起，按 D118 集中进行）

建议每项玩几分钟，不必全做：

1. **自己写一个开局**：在“新的故事”里写故事设定（可以是架空朝代），“更多设置 → 时代设定”保持“AI 按故事设定整理”，开始。
2. 开场后点右上角“我”，看“设定”页：AI 整理的时代卡和卡片对不对、有没有和你的设定冲突；改一张、自己新建一张，过两回合提到它的名字，看 AI 有没有用上。
3. 点顶栏的日期，看“此时此地”；试着“修改纪年与货币”，再从 ⋯ 菜单撤销。
4. 用内置的唐代灵感（如“万年县不良人”）开一局，对比有卡组和没有卡组时的时代感。
5. R02 的部分：“写”模式、重说与“写短一点”、长按“回到这里”、角色面板修改钱和物品、切到后台一分钟再回来。
6. 首页长按一个世界，“用同样设定再开一局”；新游戏右上角 ⋯ 复制开局设定。
