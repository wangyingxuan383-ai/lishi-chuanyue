- 自动检查：类型检查；前端单元测试（改完后 328 项）；手机尺寸完整流程 `scripts/ui/game-flow.mjs`（88 项）；桌面宽屏 `scripts/ui/desktop.mjs`（改完后 18 项，新加 3 项）；Rust 的 fmt、clippy、测试（42 项）；文档检查 `scripts/check-docs.mjs`。
- 秘密与私人信息：全部 90 个提交里没有开发台保存的 Key 与服务地址、局域网地址、手机序列号；`.cache/dev-secrets.json` 从未入库；提交作者只有 Claude、Codex；仓库打包后约 5.2 MB，最大的文件是 260 KB 左右的截图。
- 代码审查：一个 Claude 子代理只读审查了 0.5.0 之后的全部代码改动（实际从更早的 `e7960b6` 起），并用评测存档里的真实正文直接调用引擎函数核对，没有调用模型。
- 安装包：安卓包签名、对齐、原生库、桥接类、版本号（0.8.0 / 8000）、应用名、自适应图标背景色；Windows 程序在本机启动、窗口标题、正常关闭。

## 审查发现与处理

没有发现会崩溃、丢档或损坏状态的问题。发现的问题都已改，并补了测试：

| 严重度 | 问题 | 处理 |
| --- | --- | --- |
| 中 | 宽屏时面板常驻，一边“修改”一边玩一回合，再点“保存修改”会把这一回合的变化（花的钱、得的物品、新状况）改回去 | 只保存玩家在这次修改里真正改过的内容；正在生成时“保存修改”暂不可点。桌面检查新加一项：修改中途玩一回合付钱，保存后钱数与修改都在 |
| 中 | 电脑上回车发送后输入框仍有焦点，下一回合的建议选项一直不显示 | 有鼠标键盘时，输入框空着就显示选项，开始打字才收起；手机上照旧（键盘弹出时收起）。桌面检查新加两项 |
| 低 | 正式包的内容安全策略没写图片来源，纸张主题的纸纹（一张内嵌的 SVG）在应用里会被拦下，截图里有、装上没有 | 安全策略加上 `img-src 'self' data:`；用构建产物分别套旧、新策略加载核对：旧策略拦下纸纹，新策略不拦 |
| 低 | 时长解析：“转眼三个月”被当成 1 分钟，“一个多月”“二十余日”“月余”认不出；快进的时间认不出时会误报“快进停在这里”；玩家在“这段时间做什么”里写的时长也被算进要过多久 | “转眼”“片刻”这类词只在没写具体时长时才用；认得“多、余”；只有正文写了认得出的时长才判断是否提前停下；只读“；”前面的时长 |
| 低 | 查一查老实回答“抱歉，我无法确定……”会被当成服务拒绝 | 查一查只看服务自己的拒绝信号和英文通知；英文通知在流式显示时也不再露出来（回合、开场、查一查都一样） |
| 低 | 唐卡组检查清单里的“小的”会命中“最小的儿子”“大大小小的”，“三班”会命中“分作三班” | “小的”只在句首或说话开头才算；“三班”改成“三班衙役” |
| 低 | 状况超过 12 项时删掉最早的，玩家看不到 | 这一回合下面显示“去掉 N 项旧状况” |
| 低 | 长局里写一大段“写”时组装上下文变慢（1000 回合时约 0.6 秒） | 先挑出可能匹配的回合再逐句打分，结果不变（评测 I 的 240 个真实行动逐一比对，完全一致）；很长的“写”只取前 240 字。1000 回合时 400 字的“写”从每次 181 毫秒降到 60 毫秒，短行动 8 毫秒降到 4 毫秒（电脑上） |
| 低 | 安卓启动时那一瞬的底色跟着手机的深色模式，不跟游戏主题；更新记录里写“夜间不再先闪一下亮色”说过头了 | 改了更新记录与台账的说法：网页部分第一帧就是对的主题，原生启动底色跟系统走 |

## 没有验证的

- 手机上的安装、图标、启动页、纸纹、宋体、动画流畅度、连 AI 服务：暂时无法用手机。
- 修改后的长局记忆没有再跑真实模型评测：匹配结果在评测 I 的真实行动上与改前完全一致，只有超过 240 字的“写”会少看后半段。
