> 2026-10-17（Asia/Shanghai）。审查人：Claude（子代理）。只读审查，没有改动任何代码。
> 环境：浏览器开发台 `http://127.0.0.1:1420`（Vite，已在运行），本地模拟模型 `scripts/fake-llm.mjs`（fake-normal / fake-slow / fake-http500 / fake-stall），Edge + playwright-core，393×852，deviceScaleFactor 2，isMobile/hasTouch。世界数据用 `scripts/ui/screens.mjs` 里的同一套样例（长安雪夜、汴京梦华、锦衣夜行）。
> 截图都在 `.cache/audit/shots/`（不进 Git），下文只写文件名。驱动脚本：`.cache/audit/audit1.mjs`～`audit4.mjs`。
> 没有覆盖：真机（安卓返回键、输入法顶起、后台切断网络、通知权限弹层）、真实模型的文字质量、电脑宽屏。键盘弹出只是把视口压到 520 高来模拟。

## 一、总体印象：第一次打开的五分钟

**好的地方**是真的好。纸色底、宋体正文、段首空两格、朱砂竖线标出“你：……”、回合间的小菱形，读起来像一本书，已经比大多数 AI 文字游戏耐看；流式出字顺，停止、续写、重说、版本切换、回到这里、世界线、过些日子的月报卡、查一查都能用，失败后输入框会把原话还回来。夜间主题的墨底金字很有味道。

**但前五分钟的感受是“一个做得很认真的表单工具”，还不像一个游戏：**

1. **第 0 分钟**：启动页的印章读成了“越穿”（见第 2 节第 1 条），第一眼就是错字。
2. **第 1 分钟**：连接服务这一页是 9 个服务商按钮、地址、Key、“获取模型列表”、模型、“高级”、“测试连接”、保存，**8 个控件，没有一句“推荐选哪个”**。“获取模型列表”在填 Key 前是灰的，也不说为什么；点了以后 Key 输入框被清空、标签变成“已保存，留空表示不修改”，让人怀疑刚才填的 Key 没了。
3. **第 2 分钟**：“新的故事”是一张 1540 像素高的长表单（展开“更多设置”后 3026 像素，约 3.6 屏），控件多是 38 像素高的按钮，标签用括号写说明。最好玩的入口“随便穿”只是顶栏右边一行普通文字。灵感卡只有标题和朝代，看不出这是个什么故事，没法被吸引。
4. **第 3 分钟**：点“开始”后是一个只有“落笔中…”四个字的空白页，没有返回、没有动效；开场流式写出时没有段首空两格，进入游玩页后才突然缩进，画面跳一下。
5. **第 4～5 分钟**：故事本身很好读，但所有高级操作都藏在**长按**里，而游戏一次也没有告诉玩家可以长按（计划 4.1 第 6 条的“第一次长按提示”没有做）。“重说”和版本切换的 ‹ › 只有 27～50×36 像素，状态标签看着能点却点不开，失败提示只有一句话、没有“再试一次”按钮。

一句话：**读的体验接近成熟产品，操作的体验还停在“工程师能用”**。差距主要在：首屏引导、点击区大小、反馈闭环（失败、死亡、生成中离开）、重复或互相打架的提示，以及几处一眼可见的瑕疵（印章倒字、日期重复、底栏挡内容）。

## 二、逐屏问题

严重度：**高** = 第一次玩就会撞上、明显不对或损害信任；**中** = 用久了会烦、看着不精致；**低** = 打磨项。

## 三、最能提升“完成感”的 20 件事

按“投入小、玩家马上能感到”排序。

1. **修好印章“越穿”**：拆成两个竖排 span 或换成图标图片（1.1）。
2. **首页以“继续”为主**：最近的世界做成大卡加“继续”按钮，“开始新的故事”降为次要；卡片加朝代小印章（2.1、2.4）。
3. **第一次长按提示，每段加“⋯”入口**：让改写、回到这里、记住这件事被玩家发现（4.2、6.1）。
4. **全局点击区改成 44 像素**：分段按钮、选项、重说、版本 ‹ ›、页签、summary，设计规范一起改（4.3、11.2）。
5. **修长按穿透**：长按“重说”或选项时不再同时打开整段的菜单（4.4）。
6. **中断和失败只留一个提示框，并带操作按钮**：续写 / 重说 / 再试一次 / 换个服务；撤销等操作后清掉旧提示（5.1、5.2、5.3）。
7. **死亡做成“结局卡”**：生平一句、回到几回合前、回到书签、再开一局（5.6）。
8. **顶栏标题不再重复日期**：没有地点时用世界名（4.1）。
9. **开局页减负**：第一屏只有灵感 / 随便穿 / 一句话，其余折叠成摘要行；“随便穿”做成大卡（3.1、3.3）。
10. **灵感卡加一句故事钩子，高度统一**（3.4）。
11. **吸附底栏和吐司不再挡内容**：底栏加双线和渐隐，吐司避开底部控件（3.2、11.1）。
12. **连接服务合成一个“连接并开始”**：服务商列表带推荐和一句话说明，Key 以遮罩形式保留显示，不自动选错模型（1.3、1.5、1.6、1.7）。
13. **点状态标签能看本回合的变化，同项加减合并**；🎲 换成单色签（4.5、4.6）。
14. **输入模式改成可见的选择面板**，统一叫“幕后”，幕后附加栏可以关掉（4.9、4.10）。
15. **全部 `confirm()` / `prompt()` 换成应用内弹层**，有表单的弹层加“完成 / 取消”和放弃修改确认（2.2、3.11、6.2）。
16. **⋯ 菜单分组**：撤销 / 重做做成常驻图标按钮并给反馈吐司（7.1、7.2）。
