# 使用说明（开发版初稿）

> 2026-10-16（Asia/Shanghai）。本文按当前源码中的界面与行为编写，用于 M06 开发阶段；它不代表所有平台的操作验收已经完成。

当前提供私人优化预览，尚不是正式 v0.1 发行版。Windows 可直接运行 `target/release/lishi-app.exe`，已内置界面，无需开发服务；产物校验和与 Android 包见[交付说明](RELEASE.md)。其他开发启动方式、构建命令与环境要求见[开发说明](DEVELOPMENT.md)。普通浏览器预览没有连接本地核心，不能创建、游玩或导入正式世界。

Android 是优先平台，但本轮新增的七页界面、系统文件选择器与存档迁移尚未完成新包真机验收，本轮不操作手机测试。实际验证范围以[当前现场](STATE.md)和[任务台账](TASKS.md)为准。自配叙事接口和独立搜索依赖服务商、网络及账户额度；本文不保证任何真实服务可用，也不把固定演示结果当作模型质量验证。

## 开始一个世界

1. 启动 Windows 原生应用，打开“切换世界”，点击“创建新世界”。
2. 填写世界名称、国家或文明、公元年份、初始地点、主角姓名和叙事偏好。公元前年份使用负数，不填写公元 0 年。“随机背景”只选取本地示例，仍可修改，未经联网考证。
3. 点击“建立世界并进入”。开局模板可以保存和复用这些参数，不包含世界进度或密钥。
4. 初次体验可在“叙事与接口”中保持“演示剧情 · 固定规则”，尝试购买补给、工作、受伤或休息。演示不调用 AI，也不能理解所有自由行动；开局和剧情文字不等同于已核实史实。

已有世界在“切换世界”中打开。回合提交成功后，剧情与正式状态自动保存在本机；重新打开应用恢复已保存内容，不会自动重发上次行动。

## 七个页面

| 页面 | 可以做什么 |
| --- | --- |
| 剧情 | 阅读开局和最近正式回合、选择建议或提交自由行动、保存世界外叙事方针；可“跳到最新剧情”或“写下行动”。较早原文仍在世界中保存。 |
| 人物与状态 | 查看已提交的时间、地点、人物、资产、物品、关系和持续状态；新版世界按主角已知范围展示资料，未获知内容显示未知。 |
| 世界线 | 显式启用世界线、切换、分叉、重写、有限事实更正、改名、归档与恢复。 |
| 记忆 | 查找旧剧情、收藏来源回合、固定已有事实提醒、整理阶段回顾，查看来源和输入取舍。 |
| 快进 | 保存推进目标，逐段明确继续，遇到决定暂停。 |
| 历史资料 | 配置独立搜索、查询来源、记录解释与争议、将资料冻结采用到当前世界线。 |
| 存档 | 导出或导入正式 `.timejump` 存档。没有打开世界时也能导入。 |

切换页面会保留当前窗口中的页面状态；正在处理的页面会显示标记，并提供“返回正在处理的页面”。换页不会取消已经发起的操作。写操作处理中，其他写入入口会暂时禁用。

## 行动、世界外指令与两种草稿

在“剧情”的“描述你的行动”中输入主角要做的事，点击“提交行动”才执行，Enter 只换行。建议选项可直接提交为行动；“继续剧情”明确请求推进下一回合。主角死亡或世界线已归档时不能继续行动；可以从死亡前节点分叉，或先恢复归档线。

“世界外指令”中的“当前叙事方针”用于调整叙事节奏、风格等偏好。点击“保存叙事方针”后用于后续回合，不作为主角言行，不推进时间，也不能直接修改人物或资产。

尚未提交的行动文字按世界和世界线分别暂存在当前窗口，切换后可以接着编辑；关闭应用后不保留，也不会自动执行。生成过程中显示的“生成草稿 · 尚未提交”是另一种临时预览：只有核心校验通过、正文与状态一并提交后，才成为正式剧情。失败、取消或中断的生成草稿不进入后续回合上下文。

## 使用自己的 AI 接口与查看费用

打开“叙事与接口”中的“AI 接口设置”，填写服务商提供的完整 Chat Completions 端点、模型名称和 API Key，点击“保存接口配置”。默认要求 HTTPS；若明确允许 HTTP，界面会提示密钥与剧情通过网络明文传输。这里不提供或代填任何个人接口地址。

Key 加密保存在当前设备，保存后输入框清空，界面不能读回；已有 Key 时留空可保留原值。保存配置后，还需把“本次叙事来源”切换为“自定义 AI 接口”才用于行动。接口配置供本机后续请求使用，不按单个世界保存。

“发送一次连接测试”会发送简短文本，可能计费，但不改变世界。连接成功仍需实际回合验证结构化游戏输出。真正提交行动时，程序会向所配服务发送必要的背景、状态、角色已知信息、选入的历史与记忆、叙事方针和当前行动。请按服务限制设置“上下文容量”；本应用的容量设置不能证明模型实际支持相同上限。

在“叙事与接口”展开“本机模型调用记录”，点击“读取最近记录”，可查看当前版本记录的最近 100 次请求、HTTP 尝试、模型、用量与错误码。旧版本调用不会补填；“响应接收完成”还不等于回合提交成功。演示模式不发模型请求，搜索另行计数。没有可信单价时费用显示未知；Token 缺失也不能推算账单。失败、取消和中断均不会自动重试，远端仍可能已处理或计费。

需要金额估计时，展开“本机单价与费用估算”，先“读取本机单价”，选择已读取记录中的模型或填写模型名，按服务提供的价格填写币种及每百万输入、输出 Token 单价，再明确保存。两项都需填写；留空表示未配置，0表示你明确输入0。然后点击“读取当前费用估算”，在相应调用的详情查看金额。清除单价不会删除调用记录；保存或清除后需重新读取估算。

金额使用当前填写的价格重算最近记录，**不代表历史实际账单**。同名模型可能来自不同服务商，需要自行核对适用范围；币种不换算、不合计，不包含税费、缓存或推理特殊价格。缺价格或usage仍为未知，失败请求若有服务报告用量也可能产生估计金额；极小金额显示“小于0.000001”。单价仅存本机，不进入游戏存档或发送给模型，也不修改接口配置和Key。

普通回合输出校验失败时，可展开该次调用的“输出诊断”并明确读取，查看缺字段、结构或状态规则类别。这里只读取本地内存，不再调用模型；最多保留最近64条，关闭应用后清空，不含回复原文或 Key。诊断不足以判断所有语义错误，快进与 AI 回顾暂不提供这项诊断。

默认输入预算为8192字节。正式人物、事件和持续事实随长局增加，必要内容超限时会停止生成并提示容量问题；不会删除事实来强行继续。需要在接口设置按服务实际容量提高预算。本次三十回合评测使用临时扩大的容量，结束已恢复原值；这不代表默认容量足够游玩同样长的世界。

## 世界线：保留旧线，再探索变化

旧版世界先在“人物与状态”点击“备份并启用长期状态”；再在“世界线”点击“备份并启用世界线”。程序先创建一致备份，读取列表本身不会自动升级。

- “保留此节点并建立新线”：保留所选已提交回合，在其后探索不同选择。可选择开局及当前显示窗口中的回合。
- “重写此回合并建立新线”：新线停在该回合的父节点，并把原行动填回输入框。编辑后仍需手动提交，不会自动生成或覆盖原回合。
- “修正事实并建立新线”：当前只支持主角姓名和本人已有、可知的资金。保存时产生一回合本地更正记录，不调用模型；不能任意更改生死、他人资产或整份世界状态。
- “归档”保留剧情和子线；勾选“显示归档世界线”可找到并“恢复”。这里没有删除整个世界的功能。

不同世界线分别保存后续剧情、人物认知和记忆。原线分叉后新增的提醒、回顾或采用资料，不会因为恰好仍在相同回合节点就自动进入旧子线。

## 记忆与分段快进

“记忆”可以按姓名、主题或已知人物查找已提交剧情，收藏来源回合，并从已有可知事实中选择固定提醒。检索、书签和提醒不推进时间，也不把传闻变为事实。

“阶段回顾”整理最近至多十个正式回合，可选本地原文摘录或已配置 AI 接口。AI 回顾可能计费；容量或预算不足可以延后。回顾保留来源和版本，重新整理仍从原始剧情出发，旧结果保留；摘要不能代替正式事实。

使用“快进”前先启用世界线。填写“推进总天数”“每段最多推进天数”和“关注事项”，点击“保存快进目标”只登记目标。每次点击“继续一段”才处理下一段，结果保存后再次等待；不会无人值守地连续调用模型。

遇到“等待玩家决定”，回到“剧情”选择选项或提交自己的行动，再回“快进”点击“已提交决定，确认后继续快进”。确认后仍需明确点击“继续一段”。取消目标保留已提交的剧情和进度。若普通行动已使旧作业落后，按提示从当前节点新建目标。日期采用延伸公历计算，月日不明时显示范围，不是当地史历或农历换算；生日未确认时年龄未知。

## 历史资料不会直接推进世界

“历史资料”中的“独立搜索设置”与叙事 AI 接口分别配置，使用独立的搜索 Key。未配置搜索仍可继续游戏。查询历史问题不推进时间，也不调用叙事模型分析；一次独立搜索最多五条结果，通常优先使用 24 小时内缓存，勾选“忽略缓存重新查询”后明确重查。

结果摘录来自搜索摘要，未读取网页全文。请求年代仅是检索条件；没有结果不能证明历史中不存在。可以记录有来源支持、推断、争议或未知的解释，以及适用年代与依据。年代提示辅助核对，不代表已完成史实考证。

启用世界线后，点击“将这些资料用于当前世界线”保存当时的资料版本，仅增加后续叙事参考，不改变人物、资产、时间或已发生事实。后来补充解释不会改写已有采用；希望后续使用新解释时需再次采用。

## 导出、迁移与导入

在“存档”点击“导出 .timejump 存档”，通过系统文件选择器保存。导出范围是当前整个世界，包含全部世界线、原始剧情、正式状态、必要提醒与书签、回顾版本、已采用的冻结资料以及可读剧情。它可能包含当前主角看不到的状态和其他线的私人内容，应作为完整私人存档保管。

存档不包含叙事或搜索 Key、接口配置、搜索缓存和调用诊断；也不包含其他世界。存档并非只导出屏幕上最近几回合，开局模板也不能替代正式存档。

点击“导入 .timejump 存档”选择文件。程序在新暂存目录检查格式、大小、校验和、数据库结构及内容关系，全部通过后才加入世界列表并打开。本机已有相同世界 ID 时拒绝导入，不覆盖，也不会偷偷更换 ID；改标题不能绕过该规则。需要在另一台设备或独立资料目录导入时，应先备份该处已有资料，不要删除原世界来强行覆盖。

格式用于跨设备迁移，接收端必须使用支持该格式及版本的应用。导入不会携带或改写接收端的接口配置；新设备需在应用内重新配置叙事接口与搜索 Key。当前 Android 新包的选择器及跨平台导入仍待真机验收，不能将 Windows 或自动测试通过当作手机已通过。

当前每个包内文件上限 512 MiB、总包上限 1 GiB；研究资料 JSON 另有容量限制。校验和用于发现损坏，不证明文件作者可信。取消、损坏、超限或同 ID 冲突不会覆盖已有世界；外部文件保存失败时，尤其移动端文档提供器可能留下不完整文件，请以应用明确提示“存档已导出”为成功依据。

## 失败、中断和结果未确认时

1. 先看状态：已提交回合仍保留；失败、取消或中断的候选剧情没有成为正式事实。取消请求要等待核心确认，不能仅凭点击按钮判断远端停止。
2. 普通回合点击“重新读取存档”；快进使用“读取快进记录”，世界线使用“读取世界线列表”。结果仍未确认时重新打开应用，再核对剧情、回合数和作业进度。
3. 只有确认原操作失败、取消或中断后，再明确选择“重新提交上次行动”或继续相应作业。程序不自动重发，不应把未确认当成必然失败而连续点击。
4. 导入结果未确认时，先在“切换世界”核对是否已出现该世界，再决定下一步。导出失败时保留原世界，确认目标文件完整后再把它当作备份。

若世界暂时无法读取，不删除其文件，不用技术文本探针包代替游戏存档。先保留现有文件与已知有效备份，依据[开发说明](DEVELOPMENT.md)排查。技术验证入口是开发诊断工具，实际交付及尚未验证事项继续查阅[当前现场](STATE.md)。
