# M06 存档与调用记录实施契约

> 2026-10-15，Asia/Shanghai。任务状态见[台账](../TASKS.md)，实际证据见[验证](../validation/M06.md)。本文件说明已落盘协议；设备与真实服务仍按证据验收。

## 正式存档格式

`.timejump` formatVersion=1，前缀为8字节`TIMEJMP\0`、little-endian u32格式版本、u32 manifest字节长度，随后UTF-8 JSON manifest及依清单顺序排列的原始payload。无压缩、任意文件路径或可执行脚本。

manifest为严格字段：formatVersion、worldId、schemaVersion、createdAtMs、entries；每项name、sizeBytes、sha256。条目只允许world.sqlite、annotations.sqlite、research.json、story.md、sources.json，世界数据库必需。当前native的schema2/3还要求注释和冻结研究bundle；v1保持旧格式。

默认硬上限manifest64KiB、单payload512MiB、总包1GiB（含头部和清单），JSON研究资料64MiB；调用方只能缩小限制。流式64KiB缓冲校验长度/hash/EOF，拒绝重复名、未知名、额外尾部、未来版本、路径穿越、符号链接和Windows重解析路径。可读剧情写入也有512MiB限制和取消检查，不先生成无限大临时文本。

校验和证明内容完整，不能证明包的可信来源。世界SQLite在任何可写恢复前，先以read-only、trusted_schema=OFF、query_only检查精确受支持schema及完整性；拒绝额外trigger/view/table/index和改写约束。注释同样严格比较SQL token，保留字符串字面量及token边界；允许fresh v2与canonical旧v1实际升级后的两种形状，不放宽其他约束。

## 采集与发布

native占用全局世界写lease及文件选择器lease。正式库、注释通过SQLite Backup API生成一致快照，拒绝进行中的回合；采集与校验在私有临时目录，外部对话框/网络期间不持SQLite事务。正文包含所有分支原文，annotations保留固定提醒、书签、回顾及来源版本，research只含本世界冻结采用。

导入：系统选择器→私有新stage→完整容器校验→世界及每分支可信路径重放→注释范围校验→研究scope/水位校验→创建ready整目录→同私有文件系统rename为imports/世界ID的SHA256。最后rename之前列表不可见，之后世界、注释、研究和receipt作为整体可用。同ID拒绝覆盖，不改写原始world/turn ID或旧迁移指纹。

normal世界仍保存在worlds下；导入世界位于imports/<sha>/world.sqlite，并在同目录保存memory、research.sqlite和import.json。未完成stage不当世界发现；正常错误自动清理，进程强杀遗留目录保持不可见，当前尚无游戏stage启动回收。一个损坏导入不会隐藏其他健康世界，列表报告不可读数量。

Windows导出先在用户所选目录写完整临时文件并sync，再发布为选定目标。Android使用系统document URI与私有fd桥，JS不接触路径/URI。SAF写失败可能留不完整外部文档；原世界保留。取消在复制、可读导出及发布前检查，已完成发布的成功不被迟到取消回写。系统对话框开启时需由用户关闭对话框才能完成退出该步骤。

## 研究资料的跨设备隔离

WorldResearchBundle版本1包含worldId、watermark和冻结adoptions，保持原changeSeq。导入世界使用独立研究证据库，避免与目标设备共享库已有序号冲突。恢复仅允许fresh store，并设置sqlite_sequence至原watermark；之后新采用必须高于旧水位。分叉仍截断父分支在分叉后的采用，同head后新增资料不能漏入旧子线。

搜索配置、加密Key、原始共享缓存和查询operation不进包；新查询仍用本机共享配置，可信native把选定记录冻结采用到目标世界证据库。没有来源的推断保持不确定，导入不会直接修改世界事实。

## 本机模型调用台账

独立model-calls.sqlite为本机游戏诊断，不属于正式世界或导出。普通v1/v2回合、快进段、独立AI回顾及连接测试在发送前持久预留；每operation最多两项，不自动重试。FF和AI回顾既有正式预算继续保留，并额外使用统一台账。演示和本地回顾不发模型请求；独立搜索保持一次预算；技术验证页的独立探针沿用其自己的诊断，不混入游戏台账。

CallAttempt字段为operationId/worldId/branchId/model/promptVersion/sequence/state/actualHttpAttempts/sentUnknown/httpStatus/usage/elapsedMs/errorCode/createdAtMs/finishedAtMs。state为reserved/completed/failed/cancelled/interrupted；这里只记录传输结果，completed不等于正式回合已提交。模型输出解析失败依旧不推进正式世界。

预留与实际尝试分开。返回确认的attempts是0或1；进程在返回前终止时重开变interrupted，actualHttpAttempts=null、sentUnknown=true，不把无法确认的请求算作零次或释放预留额度。身份/模型/提示词版本冲突拒绝复用operation。调用记录不含endpoint、认证头、Key、prompt或响应原文；finish只接受安全错误枚举。损坏台账阻止新的付费生成，不影响离线读取世界。

get_game_calls显式返回最近100项；前端严格解析数量、数值、状态与用量一致性，只读按钮不触发模型请求。未记录旧版本历史不补填。缺usage/价格显示未知；M06-T008另设本机当前单价配置和定点金额估算，不改原台账，不进入世界包；严格字段、修订与历史价格限制见[费用契约](M06_COSTS.md)。不能声称已知实际费用。

普通回合严格解析拒绝时，另存本窗口最近64条输出诊断，按实际记录顺序淘汰，以worldId+operationId绑定。get_game_output_diagnostic需显式读取；重启即清空，不入数据库/存档。只返回固定类别、白名单字段名、JSON数字位置和回复字节数，不返回模型值、原文、serde错误全文或提示词。整体语法先检查，结构/约束诊断不授权修复或提交。快进包与AI回顾暂不接此诊断。前端按钮仅本地读取，不产生模型调用。

普通Prompt v5针对真实样本漏eventId明确必填字段；v6区分持有转移和消耗；v7用18种完整闭合JSON模板代替含糊操作签名；v8补一时辰7200秒/半时辰3600秒及事件、正文和数值时长一致性。持续事实/研究不确定性、指定行动范围及不重复付薪规则保留。协议仍为v2，正式快照/存档schema不变，失败没有自动重试。领域诊断沿原权威validate执行一次并原样返回错误，不修复或授权提交；JSON合法性不能证明正文与状态语义一致，真实样本仍须人工复核。

## 界面与持久性边界

剧情、人物与状态、世界线、记忆、快进、历史资料、存档七页保持挂载；隐藏页不参与键盘/无障碍树。忙碌时所有写入口共享占用，可返回来源页取消。应用技术页按需加载，返回游戏保留请求所有权及草稿。

行动草稿按worldId+branchId保存在当前窗口内存；切页/切线/切世界保留，成功提交清除对应未变草稿，关闭程序不保留。Enter换行，不隐式提交。正式世界和操作状态才是持久事实。手机真实输入法、切后台、系统选择器和新布局仍需设备验收；浏览器尺寸/mock结果不能替代真机。

## 兼容与依据

schema1保持原始行/输出；schema2/3保持全部分支、快进作业和迁移收据。既有显式升级仍先一致备份，未来schema拒绝。恢复现有同ID世界、克隆世界ID、压缩和更大存档另行设计。
