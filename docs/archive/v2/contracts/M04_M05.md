## 世界线与存档

正式模型输出保持protocolVersion=2，存档schema=3追加分支结构。旧v1先走原来的显式1→2一致备份迁移，再显式启用2→3；新UI世界创建后初始化3。列表读取不自动升级。旧迁移收据、原始正文、行动和快照不改写；升级失败保留备份，不提供裸拷运行中WAL的恢复捷径。

每个节点单父。game_turns.sequence是全世界插入顺序；game_turn_origins.path_sequence是节点所在路径的回合序。选线从head沿parent_turn_id核对完整路径和来源，重放出正式状态及人物已知事实。不能用全局sequence范围代替祖先证明。全局一个正式写操作；branch/head与修订CAS阻止旧结果覆盖。

分叉参数：worldId/sourceBranchId/expectedHeadTurnId/expectedRevision/operationId/newBranchId/name/forkTurnId。开局节点用null；重写传原turnId，核心从其parent节点分叉并返回原行动，UI填回输入框后等待玩家明确提交。改名、归档、恢复均用独立operationId和修订校验，归档不删子线的祖先记录。

主角姓名和本人已知cash支持明确修正：在当前head建立新线，再本地提交一个有事件来源的更正回合。姓名、金额和当前可知值校验后才提交；时间不变，无模型调用。其他事实类型、复活、任意SQL或JSON快照替换没有接口。

注释与研究各有独立change_seq。分叉冻结每域水位，检索只含祖先分叉点之前的节点和当时已采用的资料/提醒/摘要；同head之后新增内容也不能进入旧子线。索引缓存同时绑定branch和head。旧版没有叙事方针历史，所以早期回溯继承来源线当前方针；此限制不影响正式事实按节点重放。

## 快进作业

开始参数：worldId/branchId/jobId/expectedHeadTurnId/targetElapsedSeconds/maxSegmentSeconds/focus。保存目标不推进时间；每次continue明确生成一段，参数另含operationId/expectedJobRevision。UI以天输入，核心以安全整数秒保存；日历是延伸公历，支持公元前且无0年。初始月日未知时保留日期范围；生日未知不推测年龄。

状态：ready → running → segment_limit / paused_decision / completed，另有cancelled/interrupted/failed。每段包裹为output（正式v2输出）/stopReason/decision。decision为null或prompt/choiceIds，ID须对应同一输出选项，不能先生成依赖尚未决定选项的结果。

每段一条正式操作，普通回合、状态快照、head和作业进度在同一短SQLite事务提交；外部HTTP期间不持事务。每段最多预留一次模型请求；演示为0。取消/断流不提交候选，预留不复用；重试必须明确点击并使用新operationId。中断恢复不自动补发请求。

paused_decision须先另行提交一个当前线上的普通action回合，其parent是暂停节点，再用decisionTurnId确认恢复。继续操作、别线节点及另一快进段不能假冒玩家决定；死亡使后续推进停止。取消目标保留已发生事实；玩家可明确继续可恢复作业。

## 研究与引用

ResearchProvider只提供归一化历史资料；首实现Brave GET Web Search。query最多600字符、75词、1800 UTF-8字节；一次最多五条结果，响应体及超时有界，无重定向携带认证、无递归研究。来源URL仅http/https且不含认证；保存标题、摘录、snippet来源类型、取得时间、请求年代和标签。请求年代是搜索意图，不是已证实资料适用期。

手动查询不会推进时间；重要人物/生卒、官职/制度、技术、地名/交通及明确考证词在真实生成前进行有界预查询。未配置可继续游玩；失败保留不确定性。搜索与叙事使用分开的平台加密Key；前端只获configured/revision/config，不读回明文。

缓存按查询、时代、区域、标签及Provider namespace区分，默认24小时有效。重新查询产生新记录，旧来源不覆盖；采用记录冻结所选来源和当时可用结论。结论追加、冲突并存；新增结论需重新采用才进入后续上下文。来源不能直接变更人物、资产、知识或任何正式事实。

模型前登记当前冻结证据的source ID；sourceReferences必须是唯一且已登记的ID。注册只允许generating期间，由原生编译器调用，无前端任意注册命令；提交后不可追加。提交及重开重放都验证引用。上下文把资料包标为untrustedHistoricalEvidence和historicalBaselineOnly，外部资料无SQL、Shell、文件或Key权限。

研究操作保留status/searchSlotsUsed/diagnostics/httpAttemptsKnown。缓存命中0新HTTP、不读取Key；running崩溃不能确定HTTP次数则显示未知。普通提示词版本4，快进21001。Key、认证头、配置与私人世界不进入源代码、游戏导出或Git；M06正式导出仍待实现。
